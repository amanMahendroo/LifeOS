## Weekly study plan (~4.5 h active, adjustable)
No fixed weekdays (schedule is unpredictable). Blocks are done whenever time allows.
**Current focus: Schreiben and Lesen**, because they can be practiced fully in this chat. Sprechen and Hören are added once a method is set up (voice mode, transcript comparison, Modelltest).

| Block | Time | What |
|---|---|---|
| Schreiben A | 60 min | Task from tutor. 10–12 sentences with position, reason, example, counter-argument. Batched feedback. |
| Schreiben B | 30 min | Rewrite own text using the feedback. |
| Sprechen | 45 min | 2–3 min free speaking on a topic (voice mode or voice note with pasted transcript), then feedback. *(Later)* |
| Lesen | 45 min | One opinion article (Zeit, SZ, DW). Summarise argument and counter-argument in 3–4 sentences. Note 5 expressions in full sentences, not word lists. |
| Hören | 45 min | 5–10 min of *Mord auf Ex* or news, once without pausing. Written summary, then compare with transcript. *(Later)* |
| Bonus | up to +90 min | Books, conversation with partner, daily life in Germany. Passive input continues as before. |

**Principles**
- Repetition without drilling: tasks quietly re-use patterns from the PROGRESS.md mistake table so correct forms become natural.
- Increase length (start 8–10 sentences) once accuracy holds under load.
- 3-hour mini version: Schreiben A + B, Sprechen, and alternate Lesen / Hören.
